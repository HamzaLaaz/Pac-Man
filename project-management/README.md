# Project Management

This directory documents how the Pac-Man project was planned, tracked
and delivered by the two of us.

Contents:

- [`timeline.md`](timeline.md) — the six phases of the project as a
  Gantt chart, with real commit dates.
- [`kanban.md`](kanban.md) — current Done / In Progress / To Do board.
- [`progress-tracking.md`](progress-tracking.md) — what was planned for
  each phase vs. what actually landed, and when.
- [`decisions.md`](decisions.md) — the main technical choices made
  during the project and why.
- [`risk-analysis.md`](risk-analysis.md) — risks identified along the
  way and how they were mitigated.
- [`team-organization.md`](team-organization.md) — who worked on what,
  how decisions were made.
- [`acceptance-tests.md`](acceptance-tests.md) — the manual acceptance
  tests run against the subject's requirements, and the bugs they found.
- [`packaging-guide.md`](packaging-guide.md) — the step-by-step plan for
  packaging and deploying to itch.io (not executed yet).
